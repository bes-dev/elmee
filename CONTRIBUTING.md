# Contributing

Thank you for looking. elmee is small on purpose, so the most useful
contributions are bug reports with a way to reproduce them, fixes that come
with the test that would have caught the bug, and reports of where it failed
to embed in something.

Before writing code, read [AGENTS.md](AGENTS.md): it says where a change
belongs, what has to stay true, and what has already been decided against — it
is short, and it will save you a rejected pull request. For anything that
touches `core` or adds a dependency, open an issue first.

A change is ready when the commands under "Before you say a change is done" in
AGENTS.md pass and the documentation says what the code now does.

Security problems go through the process in [SECURITY.md](SECURITY.md), not
the issue tracker.

Contributions are accepted under the Apache License 2.0, as section 5 of the
[LICENSE](LICENSE) states.
